# Sambramo — image prompts (all occasions, categories and services)

## How to use

1. Open ONE new ChatGPT chat and send the SETUP MESSAGE below once.
2. Then send one line at a time, exactly as written (ID + scene).
3. Save each image with its ID as the filename, e.g. `occ-haldi-ceremony.png`.
4. Put everything in one folder (sub-folders by section are fine) and send me the path.

Regenerate any image that has: text or letters, extra/odd fingers, a background that is not pure white, or figures cut off at the edges.

## SETUP MESSAGE (send once, at the start of the chat)

> For every image in this chat, use exactly this style: high-quality 3D animated character illustration — soft rounded features, large expressive friendly eyes, smooth glossy skin, Indian characters in detailed Indian clothing and jewellery, warm soft studio lighting, heartfelt emotion that fits the scene. Original characters only; do not resemble any real person, celebrity, or existing film or cartoon character. Isolated on a pure white background, no scenery, no floor, no ground shadow; the bottom of the figures fades softly into white. Characters shown from the waist or knees up, centred, with white space around them. Only the props named in the scene. No text, no letters, no logos, no brand names, no watermark. Square 1:1, 1024×1024. Keep the same art style, lighting and character quality in every image.
